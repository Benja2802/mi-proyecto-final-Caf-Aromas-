# Café Aroma – Proyecto final de Git y GitHub

Sitio web de la cafetería "Café Aroma", hecho con HTML y CSS. Este repositorio es la actividad integradora del curso Introducción a Git y GitHub.

## Objetivo

Aplicar los conceptos de repositorio, commit, rama, remoto, pull request y documentación básica sobre un proyecto web real.

## Estructura

```
mi-proyecto-final/
├── README.md
├── docs/
│   └── notas.md
├── src/
│   ├── index.html
│   ├── menu-completo.html
│   ├── encuesta.html
│   └── styles.css
└── recursos/
    └── image/
```

- `README.md`: descripción del proyecto.
- `docs/`: documentación complementaria y notas.
- `src/`: páginas HTML y hoja de estilos.
- `recursos/`: imágenes del sitio.

## Cómo usarlo

1. Clonar el repositorio: `git clone https://github.com/Benja2802/mi-proyecto-final-Caf-Aromas-.git`
2. Abrir `src/index.html` en el navegador o con Live Server.

## Flujo de trabajo con Git

- Rama principal: `main`.
- Rama de trabajo: `feature/mejoras-encuesta` (ortografía y botones de la encuesta, enlace a Reservas).
- Los cambios se integraron a `main` mediante el pull request #1.
